# Документация проекта

## Что здесь лежит

- `baseline/` — снимок состояния сайта на 15.09.2026 и 29.09.2026: аудит текстов, документов, альтернативных текстов, происхождения ассетов, политика утверждения контента, проверки внешних источников, таблица редиректов, манифесты URL и зависимостей.
- `reports/` — отчёты по этапам переработки V2 (шапка, подвал, hero, новости, хлебные крошки, метаданные, sitemap/robots, доступность).
- `archive/` — завершённые чек-листы V2.
- `design/` — палитра цветов.
- `css-audit-2.7.3.md`, `COLLECTIONS_SETUP.md`, `MIGRATION_PLAN.md` — прочее из периода миграции.

## Происхождение

Отчёты перенесены из репозитория `DimaNikolaevi4/site` (ветка `site-v2`) в октябре 2026 — перед выводом того репозитория из эксплуатации. Это исторические артефакты: они описывают, как делался V2, и не являются инструкцией к текущему состоянию кода.

## Важно

- `baseline/2026-09-29/URL_MANIFEST_V2.tsv` — не исторический документ, а рабочая фикстура: на неё опирается проверка `npm run check:urls:generated:v2` в CI. Не удалять и не перемещать без правки скрипта.
- Папка `src/docs/` в репозитории отсутствует намеренно: 291 файл документов (лицензия, рабочие программы, локальные акты) опубликован напрямую на хостинге в `public_html/docs/`. Подробности — в [DEPLOY.md](DEPLOY.md).
